# Articiti Gallery

Build the full ARTICITI platform — a premium, highly immersive website for ARTICITI, a luxury Indian devotional wall-art and 3D wall sculpture brand — consisting of TWO connected experiences that share the same Supabase backend/database:

1. PUBLIC CUSTOMER WEBSITE
2. SECURE ADMIN DASHBOARD (at /admin, authenticated, only accessible to authorized admins)

The public website must be fully database-driven — never hard-code products, prices, materials, categories, finishes or pricing rules in frontend components. Everything editable must be manageable from the Admin Dashboard and read dynamically by the public site.

=====================================================
PART 1 — PUBLIC WEBSITE SPEC
=====================================================

Create a premium, highly immersive website for ARTICITI, a luxury Indian devotional wall-art and 3D wall sculpture brand.

The website must combine:

MODERN LUXURY
+
TRADITIONAL INDIAN ARCHITECTURE
+
DEVOTIONAL ART
+
3D WALL SCULPTURE
+
PREMIUM INTERIOR DESIGN

The website should NOT look like a generic e-commerce store.

It should feel like entering a luxury Indian architectural gallery.

The website must immediately communicate:

"We create extraordinary devotional wall installations for modern Indian homes."

The visual experience should be sophisticated, cinematic, calm, luxurious and premium.

Do NOT make it overly religious, colorful, crowded or temple-like.

Use subtle Indian architectural elements such as:
- arches
- carved patterns
- jaali
- lotus geometry
- temple-inspired framing
- brass details
- stone textures
- wood
- subtle Om symbols
- subtle trishul motifs

But integrate them into a contemporary luxury interior-design aesthetic.

=====================================================
PART 2 — ADMIN DASHBOARD SPEC
=====================================================

This project must include TWO separate experiences sharing the same backend database (Supabase). The public website must NEVER hard-code products, prices, materials, categories or quotation rules — everything editable must be manageable from the Admin Dashboard. The Admin Dashboard must be protected with authentication; only authorized admins can access /admin; public visitors must never access, modify or delete admin data.

ADMIN LOGIN — Route: /admin/login. Clean premium login screen: ARTICITI logo, "Welcome to Articiti Admin", fields Email/Password, LOGIN button, "Forgot Password" link. No admin info exposed pre-auth. On success redirect to /admin.

ADMIN DASHBOARD HOME — Route: /admin. Header "ARTICITI ADMIN" with admin profile + logout on right. Dashboard cards showing real DB values (not fake stats): Total Products, Active Products, New Enquiries, Quotations, Orders, Estimated Enquiry Value.

ADMIN SIDEBAR — Desktop: Dashboard, Products, Categories, Materials, Pricing Rules, Finishes, Enquiries, Customers, Orders, Media, Website Settings; bottom: Admin Profile, Logout. Convert to a drawer menu on mobile.

PRODUCT MANAGEMENT — Route: /admin/products. Table/grid of all products showing image, name, category, starting price, status, featured, last updated. Actions: Edit, Duplicate, Preview, Archive, Delete. "+ ADD PRODUCT" button.

ADD / EDIT PRODUCT — Routes: /admin/products/new and /admin/products/:id/edit. Fields: Product Name (e.g. "Krishna Playing Flute"), Category (e.g. Shri Krishna), Short Description, Long Description, Starting Price (e.g. ₹15,000, always displayed publicly as "Starting from ₹15,000"). Uploads: Main Product Image, Gallery Images, Side View, Close-up, Installation Image, AI Visualization Image, Product Video. Product Info — Suitable For: Living Room, Mandir, Feature Wall, Entrance, Bedroom, Office. Available Materials: HDHMR, MDF, Gypsum/POP, FRP/Fibre, Acrylic, Custom. Available Finishes: Stone, Antique, Gold Accent, Metallic, Artist Painted, Custom. Product Status: Draft/Published/Archived. Featured: Yes/No. Auto-generate SEO-friendly slug (e.g. /products/krishna-playing-flute). Buttons: SAVE DRAFT, PUBLISH, CANCEL.

DUPLICATE PRODUCT — Admin can duplicate an existing product (e.g. "Krishna Playing Flute" → "Krishna Standing"), copying category, materials, finishes, pricing rules, description; admin only needs to change name, images, description.

CATEGORY MANAGEMENT — Route: /admin/categories. Add/Edit/Archive categories. Initial categories: Shri Krishna, Mahadev, Ganpati Bappa, Bajrang Bali (allow future categories). Each category: Name, Description, Cover Image, Status, Display Order. Public category pages must auto-use this database.

MATERIAL MANAGEMENT — Route: /admin/materials. Add/Edit/Archive materials. Initial examples: HDHMR, MDF, Gypsum/POP, FRP/Fibre, Acrylic. Each material: Material Name, Short Description, Long Description, Base Rate, Pricing Unit, Image, Active/Inactive. E.g. HDHMR, Pricing Unit: Per sq.ft., Base Rate: admin-entered. Never hard-code this price — quotation calculator must reflect admin changes automatically.

PRICING RULES — Route: /admin/pricing. Flexible pricing engine, not hardcoded into frontend. Admin can modify: Base product price, Material rate, Size calculation, Thickness adjustment, Finish cost, Painting cost, Installation cost, Delivery cost, Additional complexity, Minimum order price, Price range/margin. Support formulas, e.g.: Base Product Price + Material Cost + Size Cost + Thickness Cost + Finish Cost + Painting Cost + Installation Cost = Estimated Price. Allow different pricing rules per product and material.

SIZE CALCULATION — Customer enters Width/Height (e.g. 5 ft × 4 ft) → auto-calculate area (20 sq.ft). Admin chooses per-product pricing mode: Per sq.ft, Fixed, Custom, or Hybrid. For fixed/custom products, show "Request Final Quotation" instead of a fake exact calculation.

THICKNESS MANAGEMENT — Thickness not necessarily customer-selected. Admin defines recommended thickness ranges per product/material combination (e.g. HDHMR: 25mm/50mm/75mm; FRP: Custom; Gypsum/POP: Design dependent). Customer sees: "Thickness is customized according to design and size," with admin-controlled options shown if needed.

FINISH MANAGEMENT — Route: /admin/finishes. Add/Edit/Archive/Set pricing. Examples: Stone White, Antique, Gold Accent, Metallic, Artist Painted, Custom. Each finish: Name, Description, Additional Cost, Image, Active/Inactive.

QUOTATION ENGINE — Public quotation calculator reads values dynamically from the database. Flow: Product → Size → Material → Finish → Installation → Estimated Price. Example: Krishna & Radha, 5×4 ft (20 sq.ft), HDHMR, Artist Painted, Installation Yes → Estimated Price ₹18,500–₹22,000. Always show "Estimated price" and the variance disclaimer; never present the automated estimate as a final confirmed price.

ENQUIRY MANAGEMENT — Route: /admin/enquiries. Every website enquiry appears here automatically. Table columns: Customer, Product, Category, Size, Material, Finish, Estimated Price, City, Date, Status. Statuses: NEW, CONTACTED, QUOTED, NEGOTIATING, WON, LOST. Admin can change status; clicking opens full enquiry detail.

ENQUIRY DETAIL — Shows Customer Name, Phone, WhatsApp, Email, City, State, Selected Product + Image, Size (Width/Height/Area), Material, Finish, Installation, Estimated Price, customer's uploaded wall image, Customer Message, Date Submitted, Admin Notes, Status. Buttons: OPEN WHATSAPP, SEND EMAIL, CHANGE STATUS, ADD NOTE.

WHATSAPP INTEGRATION (admin side) — Primary number 8010129969. "OPEN WHATSAPP" generates a pre-filled message summarizing the enquiry (product, size, material, finish, estimated price) which the admin can edit before opening WhatsApp.

CUSTOMER MANAGEMENT — Route: /admin/customers. Store customers from enquiries: Name, Phone, WhatsApp, Email, City, Total Enquiries, Total Orders, Last Contacted, Customer Status. Clicking a customer shows all their enquiries and orders.

ORDERS — Route: /admin/orders. No payment integration yet; orders created manually from enquiries. Statuses: ENQUIRY, QUOTATION SENT, ORDER CONFIRMED, IN PRODUCTION, ARTIST FINISHING, READY, INSTALLATION SCHEDULED, INSTALLED, COMPLETED, CANCELLED.

MEDIA LIBRARY — Route: /admin/media. Manage product images, AI visualizations, real installation photos, videos, material images, finish samples. Each item: Image, Type, Associated Product, Upload Date.

REAL VS AI LABELING — Every image classified as "AI VISUALIZATION" or "REAL INSTALLATION." Public site must clearly label AI images and never present them as actual customer installations.

REAL INSTALLATION MANAGEMENT — Route: /admin/installations. Fields: Project Name, Customer City, Product, Size, Material, Finish, Installation Date. Uploads: Before Image, After Image, Final Installation Images, Video. Mark Featured Installation. These auto-populate the public "Real Installations" section.

WEBSITE SETTINGS — Route: /admin/settings. Admin can update: Brand Name, Tagline, WhatsApp Number, Instagram URL, Contact Email, Footer Text, Social Links. Current values — Instagram: https://www.instagram.com/interior_by_veera/, WhatsApp: 8010129969, Contact email: rushikeshbramhankar.dev@gmail.com. Never hard-code these in the frontend — read from settings DB so changes propagate site-wide automatically.

HOMEPAGE CONTENT MANAGEMENT — Admin controls Hero heading, Hero subheading, Hero image, Hero CTA, Featured products, Featured categories, Featured installations — add/remove/reorder/publish without code changes.

FEATURED PRODUCTS — Admin marks Featured = Yes/No; homepage automatically reflects it.

ANALYTICS — Route: /admin/analytics. Display real (not fake) data: Total website visitors, Product views, Most viewed products, AI visualization requests, Quotation requests, Enquiries, WhatsApp clicks, Conversion rate, Most requested categories, Most requested materials.

SECURITY — Admin dashboard private with authentication and proper DB access rules. Only authorized admin accounts can Create/Edit/Delete/Publish/Modify pricing/View customer info. Public users can only View products, Submit enquiries, Upload wall image, Request visualization, Request quotations — never modify pricing, create products, access customer data, access admin pages, or modify DB records directly. Never expose private API keys or service-role credentials in frontend code.

EMAIL NOTIFICATION — On enquiry submission, send an email to rushikeshbramhankar.dev@gmail.com containing: NEW ARTICITI ENQUIRY, Customer/Phone/Email/City, Product/Size/Material/Finish/Installation, Estimated Price, Customer Message, Link to Admin Enquiry. Enquiry must also appear in /admin/enquiries.

ADMIN NOTIFICATION — In-dashboard notification "New enquiry received" on new enquiries, clickable to open it.

NO PAYMENT INTEGRATION FOR NOW — Flow is: Get Estimate → Submit Enquiry → WhatsApp/Email → Manual quotation → Manual order confirmation. Payment may be added later.

DATABASE STRUCTURE — Suggested tables: users, admin_users, categories, products, product_images, materials, finishes, pricing_rules, product_materials, product_finishes, quotations, enquiries, customers, orders, installations, media, website_settings, analytics_events. Use proper relationships, avoid unnecessary duplication.

IMPORTANT ARCHITECTURE RULE — The public website must be database-driven. Do NOT create hardcoded arrays like `const products = [...]` or hardcoded values like `const price = 15000` inside frontend components. Products, categories, materials, finishes and prices must come from the database, with the admin dashboard as the source of truth.

FINAL SYSTEM FLOW —
Customer: Instagram → Product Page → Choose Design → AI Visualization → Get Quotation → Enter Size → Choose Material → Choose Finish → Estimated Price → Submit Enquiry → WhatsApp/Email
Admin: Login → Dashboard → Products → Pricing → Materials → Enquiries → Customers → Orders → Installations → Analytics

Everything connects to the same database. The admin should be able to run the whole website without touching code. Architecture should scale from 10 products to 1,000+ products. Do not build a marketplace/vendor portal yet, but keep the architecture extensible for that later.
